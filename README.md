# Portafolio de Desarrollo Web

Portafolio web responsivo que presenta cuatro proyectos desarrollados durante la formación en Desarrollo de Sistemas Web: Farmacia DermaPiel, Boutique Natura, Hawaii Turismo y CodeJalisco.

## Tecnologías
- HTML5 para la estructura semántica.
- CSS3 para el diseño adaptable, tarjetas, composición visual y efectos.
- JavaScript para la navegación móvil.
- Google Fonts (Manrope y DM Sans) para tipografía.
- Fotografías remotas de Unsplash como recursos visuales representativos.

## Cómo ejecutar
1. Descarga y extrae el archivo ZIP.
2. Abre `index.html` en un navegador moderno.
3. Para desarrollo local, puedes abrir la carpeta con Visual Studio Code y usar la extensión Live Server.

No requiere instalación de dependencias ni servidor para la presentación básica.

## Estructura
- `index.html`: contenido, descripciones, imágenes representativas y enlaces a los cuatro proyectos.
- `styles.css`: estilos, composición visual y reglas responsivas.
- `script.js`: comportamiento del menú móvil.
- `assets/`: capturas originales extraídas del PDF proporcionado y versiones compuestas con una barra de navegación gris inspirada en la referencia.

## Imágenes
Las tarjetas utilizan las capturas proporcionadas en el archivo PDF adjunto. En la parte superior se integró una barra gris inspirada en la referencia; las capturas originales se conservaron sin recortar ni deformar. Los archivos originales también se incluyen en `assets/`.

## Publicación
Puede publicarse como sitio estático en GitHub Pages, Netlify o un servicio equivalente. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets/` al repositorio o proyecto de alojamiento.

## Accesibilidad y adaptación
Incluye estructura semántica, enlaces con etiquetas accesibles, texto alternativo en imágenes, navegación móvil y estilos para reducir movimiento. Se recomienda comprobar los enlaces y la visualización en el navegador antes de publicarlo.
